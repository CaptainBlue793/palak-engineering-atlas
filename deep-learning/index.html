One code style, all the way through

Every listing is Python with PyTorch, run on one 16 GB GPU, and follows the same five rules, so each one is also a small lesson in training code whose numbers you can trust. This is the style, stated once and never broken.

  • Shapes in the comments. Every tensor's shape is written next to the line that makes it, because most silent bugs are a broadcast or a wrong axis.
  • Overfit one batch first. A new model must drive the loss on a single batch to almost zero before it sees the full data set, or something is wired wrong.
  • Baselines first. Every network is compared with something simpler on the same split: a linear model, gradient boosting, or predicting the majority class.
  • Seeds, not single runs. Results come from several seeds, and a difference smaller than the spread between seeds is not reported as a win.
  • Timed honestly. GPU timings synchronise before the clock stops and skip warm-up steps, because CUDA kernels run asynchronously.
import torch, torch.nn as nn, torch.nn.functional as F

model = nn.Sequential(nn.Linear(784, 256), nn.ReLU(), nn.Linear(256, 256), nn.ReLU(),
                      nn.Linear(256, 10)).to("cuda")
opt = torch.optim.Adam(model.parameters(), lr=1e-3)        # torch 2.11, seeds 0, 1, 2

for xb, yb in loader:                                  # xb (128, 784), yb (128,)
    logits = model(xb)                                   # (128, 10) raw scores
    probs = logits.softmax(-1)                            # looks tidy, and is the bug
    loss = F.cross_entropy(probs, yb)                    # it applies log-softmax again
    opt.zero_grad(); loss.backward(); opt.step()

On Fashion-MNIST, 10 epochs, three seeds: passing the logits straight to cross_entropy reached 88.5–88.7% test accuracy. With the extra softmax it still trained, with no error and no warning, and reached 85.8–86.1%. Its loss never fell below 1.55, because the values it is fed sit between 0 and 1 and a second softmax over them can never be confident: the best it can possibly score is log(1 + 9/e) = 1.46. The first gradient was 10 times smaller (norm 0.072 vs 0.718). A bug that still trains is the worst kind, which is why losses take logits (Chapter 7) and why the debugging chapter plants this one on purpose (Chapter 39).
