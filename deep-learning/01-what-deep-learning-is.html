What Deep Learning Is

Classical machine learning splits the work in two: a person turns raw data into features (word counts, colour histograms, the age of an account), and a model such as logistic regression or gradient boosting learns how to weigh them. Deep learning hands the first job to the model too. A deep network is a stack of simple, differentiable layers trained end to end, so the early layers learn their own features from raw input, and the later layers learn to use them. When the right features are hard to write down, as with pixels, audio and text, that changes everything. When they are already in the columns of a table, it often changes nothing.

This chapter measures both halves of that sentence. On CIFAR-10 photographs, a small convolutional network reached 90.4% test accuracy, while logistic regression and gradient boosting on the raw pixels reached 40.0% and 55.7%. With only 1,000 training images, the CNN still scored 60.2%, more than boosting managed with fifty times the data. Linear probes inside the trained network show why: a straight-line classifier on its deeper features scored 89%, against 36% on the pixels. Then two tables, house prices and forest cover types, where gradient boosting beat a neural network, as it usually does.

From linear models to learned features

A linear classifier on raw pixels gives each pixel one weight per class. It can learn “cars are often grey in the middle of the image” but not “a car has wheels below windows”, because that is a statement about arrangements of pixels, and an arrangement can sit anywhere in the frame. On CIFAR-10’s 32 × 32 colour photographs of ten kinds of object, logistic regression on all 3,072 pixel values reached 40.0% (chance is 10%). Gradient boosting, which can learn non-linear combinations of features, reached 55.7%, and took 312 seconds on 16 CPU cores to get there.

A deep network replaces the hand-made feature step with layers that learn it. Each layer is a linear map followed by a non-linearity; stacking them lets later layers build on what earlier ones compute. A convolutional network also builds in two assumptions about images, that nearby pixels matter together and that a pattern means the same thing wherever it appears (Chapter 16). Trained end to end, with the loss at the top and gradients flowing back to the first layer (Chapter 4), the network discovers its own edge detectors, textures and parts.

cnn = nn.Sequential(                                         # x (B, 3, 32, 32)
    conv_bn_relu(3, 64), conv_bn_relu(64, 64), nn.MaxPool2d(2),       # (B, 64, 16, 16): edges, colours
    conv_bn_relu(64, 128), conv_bn_relu(128, 128), nn.MaxPool2d(2),  # (B, 128, 8, 8): textures, parts
    conv_bn_relu(128, 256), nn.MaxPool2d(2),                        # (B, 256, 4, 4)
    nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(256, 10))       # (B, 10) logits; 559,178 parameters
# trained 30 epochs, AdamW + one-cycle schedule, random crops and flips, bf16: 41 s on the GPU, 90.4% on the test set

Depth and representation

What has the network learned? One way to look is a linear probe: freeze the trained network, take the activations at some layer for 10,000 training images, and fit a plain logistic regression on them. If a straight line can separate the classes in that layer’s space, the layer has turned the problem into an easy one. Measured on the trained CNN, probing the test set:

Features fed to logistic regressionDimensionsTest accuracy
Raw pixels3,07236.0%
After the first convolution1,024 (pooled)58.7%
After block 11,024 (pooled)60.5%
After block 22,048 (pooled)86.5%

Each block makes the classes more linearly separable, with the biggest jump in the middle of the network, and the last layer squeezes the useful information into 256 numbers. This is representation learning, and it is the reason the word “deep” matters: the depth is where the features are built. The probe’s 89.3% is close to the network’s own 90.4% because the network’s final layer is itself a linear classifier on those 256 features. (These features were learned from the same labels; Chapter 20 probes features learned without them.)

Where deep learning wins

On the images, the CNN won at every training size, and its lead grew with data: 60.2% against boosting’s 32.7% at 1,000 images, 90.4% against 55.7% at 50,000. Two details are worth more than the headline. First, the MLP did no better than boosting (53.8% at 50,000): a fully connected network sees 3,072 unrelated inputs, just as boosting does, so it has no advantage on pixels. The win comes from an architecture whose structure matches the data, not from “neural networks” as such. Second, the CNN with 1,000 images beat every other model with 50,000, because its built-in assumptions do much of the work that data would otherwise have to do.

The same pattern holds wherever the raw input has structure a person cannot easily turn into columns: images and video (Computer Vision), speech and audio, text (NLP), and sequences of events. It also holds where you want to learn one representation and reuse it across many tasks (transfer learning, Chapter 28), which is how large pretrained models are used today.

Where it does not

Tables are different. Their columns are already features someone chose (the median income of a district, the elevation of a plot), each column means something different, and there is no locality or repetition for an architecture to exploit. On two standard tables:

One honest footnote: boosting’s first covertype run scored 58.9%, because without L2 regularisation its leaf values blew up on the rarest classes (0.5% of the data) and training accuracy fell as trees were added; with l2_regularization=1.0 it reached 94.1%. Every model has failure modes that look like “this method does not work”. Chapter 29 runs the tabular comparison properly, with tuning budgets for both sides and the neural architectures designed for tables. The default advice survives that: for a table, start with gradient boosting.

The cost: data, compute, tuning

Deep learning’s advantages are paid for. It needs data: the CNN gained 30 points between 1,000 and 50,000 images, and the largest models are trained on billions of examples. It needs compute: the CNN’s 559,178 parameters took 41 seconds on a 16 GB GPU for 30 epochs, which is cheap, but the scale of Chapters 21 to 24 exists because real models are not. And it needs tuning: architecture, initialisation (Chapter 9), optimiser and learning rate (Chapters 11 and 12), regularisation (Chapter 13), normalisation (Chapter 14), and dozens of smaller choices, each of which can quietly ruin a run (Chapter 39). The rest of this course is about paying those costs efficiently.

Use case: two models in one factory

A manufacturer wants to catch defective circuit boards. One team trains a gradient-boosted model on the sensor log of each board (oven temperatures, solder-paste volumes, timing), 40 well-understood columns, and it flags 70% of defects at a 1% false-alarm rate. Another team trains a CNN on photos of the finished boards, learning to see cracks and bridges no column describes. Neither model replaces the other: the CNN finds visual defects the sensors cannot measure, the boosted model finds process drift before it becomes visible. The production system runs both and alerts if either fires.

⚠️
Common mistakes
  • Reaching for a network on a table without a gradient-boosting baseline: boosting won both tables here.
  • Thinking “neural” is the advantage: on pixels the MLP (53.8%) did no better than boosting (55.7%); the CNN’s structure made the difference.
  • Assuming deep learning needs huge data in every case: with a fitting architecture, 1,000 images beat every other model’s 50,000.
  • Comparing a tuned network with an untuned baseline, or the reverse: boosting fell to 58.9% without regularisation.
  • Ignoring the costs: GPUs, data collection and the time to tune are part of the comparison.

Interview drill

Explain it simply: What is the difference between deep learning and classical machine learning?

How a strong answer sounds
In classical machine learning a person engineers the features and a model learns to combine them. In deep learning the model is a stack of differentiable layers trained end to end, so the early layers learn the features themselves from raw input. That matters most when good features are hard to write down, as with images, audio or text. I measured it on CIFAR-10: logistic regression and gradient boosting on raw pixels reached 40% and 56%, a small CNN reached 90%, and a linear classifier on the CNN’s deeper layers reached 89%, which shows the network had built features in which the classes are nearly linearly separable.

Deeper: A stakeholder asks for a deep-learning model for customer churn, from a table of 40 account features. What do you say?

How a strong answer sounds
I would start with gradient boosting, because on tables of hand-chosen features it is usually as good as or better than a neural network, trains in seconds on a CPU, needs far less tuning, and is easier to explain. The columns are already features, and each means something different, so there is no structure like locality for a network to exploit. On two public tables I measured boosting ahead: R² 0.858 against 0.80 for house prices, and 94.1% against 89.9% on forest cover types. A network becomes worth trying if there is raw data alongside the table, such as event sequences or text, or if we need one learned representation shared across several tasks. Either way the comparison would be on the same split with several seeds.

🧠 Key takeaways

  • Deep learning trains a stack of differentiable layers end to end, so the network learns its own features.
  • On CIFAR-10 a CNN reached 90.4% against 55.7% for boosting and 40.0% for logistic regression on pixels.
  • Linear probes rose from 36% on pixels to 89% on the CNN’s deep features: depth builds representations.
  • The win came from an architecture that fits the data; an MLP on pixels did no better than boosting.
  • On tables of chosen features boosting won (R² 0.858 vs 0.80; 94.1% vs 89.9%): start there.
  • Deep learning costs data, compute and tuning; most of this course is about paying them well.
