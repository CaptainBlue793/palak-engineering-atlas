Multilayer Perceptrons

Stack neurons into a layer, stack layers with a non-linearity between them, and you have a multilayer perceptron (MLP), the plainest deep network and still a part of almost every other: the feed-forward block inside each transformer layer is an MLP. Chapter 2 showed that two hidden units solve XOR. This chapter asks how far that goes. How many units does a curve need? Does it matter whether they are arranged wide or deep? And what does a hidden layer actually do to the input space?

Each question is measured. One hidden layer of ReLU units fitted a wavy 1-D function with error 0.42 using 2 units and 0.0007 using 256: universal approximation, made visible as a curve of straight pieces. A sawtooth with 32 teeth can be represented exactly by a 5-layer network with 31 parameters, yet no network trained by gradient descent got close; even with 8 teeth, only 1 run in 10 found it. On two interleaved spirals a linear model scored 63.5%, one hidden layer of 64 units 99.3%. And on Fashion-MNIST, going from one hidden layer to four added at most 0.4 points at any width.

Stacking layers

A layer maps a vector to another vector: h = φ(Wx + b), with W of shape (out, in). An MLP is a composition of layers, the last of which has no activation and outputs logits (for classification) or values (for regression). In PyTorch it is a few lines:

model = nn.Sequential(                         # x (B, 784)
    nn.Linear(784, 256), nn.ReLU(),               # (B, 256): 784 × 256 + 256 = 200,960 parameters
    nn.Linear(256, 256), nn.ReLU(),               # (B, 256): 65,792
    nn.Linear(256, 10))                         # (B, 10) logits: 2,570
sum(p.numel() for p in model.parameters())        # 269,322

Parameters grow with the product of neighbouring widths, so the first layer, which meets the 784-pixel input, holds three quarters of them. Doubling every hidden width roughly quadruples the middle layers.

Universal approximation

The universal approximation theorem (Cybenko 1989; Hornik 1991) says one hidden layer with enough units can approximate any continuous function on a bounded region as closely as you like. For ReLU there is a picture to go with it: each hidden unit max(0, wx + b) is a hinge with its kink at x = −b/w, and the output is a weighted sum of hinges, so a one-hidden-layer ReLU network in one dimension is a piecewise-linear function with at most one kink per unit. More units, more pieces, a closer fit. Measured on f(x) = sin 2x + 0.5 sin 7x · e^(−x²/2) over [−3, 3], best of 3 seeds:

Width vs depth

Depth can be exponentially more efficient than width. The triangle map t(x) = 1 − |2x − 1| folds [0, 1] in half; composing it k times gives a sawtooth with 2ᵏ teeth. One triangle is two ReLUs, t(x) = 2·relu(x) − 4·relu(x − 0.5), so k layers of width 2 represent a 32-tooth sawtooth exactly with 31 parameters (checked: maximum error 5 × 10⁻⁷). A single hidden layer needs a kink for every one of the 63 corners, so at least 64 units. Depth composes; width only adds.

Representing a function is not the same as learning it. Trained from random weights with Adam, no network got close to the 32-tooth sawtooth: deep or shallow, from 193 to 1,953 parameters, the best error was 0.058 to 0.081, close to the 0.083 you get by predicting the mean everywhere. With 8 teeth, out of ten seeds each, a single-layer network of 32 units solved it once (error 0.0005) and no deep configuration did (best 0.029, for 3 × 6). The exact deep solution exists, but gradient descent from a random start rarely reaches it: the loss surface for such sharply folded functions is full of poor local minima. This is the central tension of deep learning, and most of Chapters 9 to 15 (initialisation, optimisers, normalisation, residual connections) are about making deep networks trainable, not merely expressive.

Decision boundaries

In two dimensions you can watch capacity directly. Two interleaved spirals are the classic test: no line separates them, and the boundary must wind round the origin three times. A linear model drew a line and scored 63.5% on test points. One hidden layer of 8 ReLU units (42 parameters) drew a coarse polygon, 78.5%. One layer of 64 units (322 parameters) followed both arms, 99.3%, and three layers of 64 (8,642 parameters) reached 100%. Every ReLU network’s boundary is made of straight segments, one per region where the same set of units is active; more units and more layers mean more, smaller regions.

Parameters vs accuracy

On real data the returns diminish quickly. Fashion-MNIST, ten epochs, three seeds each:

Width helped at every depth (about 2 points from 32 to 512 units). Depth beyond two layers added nothing measurable: the standard deviation across seeds was 0.05 to 0.5 points, larger than most of the depth differences. For flattened images, an MLP has no way to exploit spatial structure (Chapter 1), so extra layers have little to build on; the architectures of Chapters 16 to 19 are where depth pays.

🛒
Use case: the MLP inside a recommender

A retail recommender embeds users and products (Chapter 20) and feeds the concatenated vectors to an MLP that predicts purchase probability. The team tries widening the MLP from 256 to 1,024 units and deepening it from 3 to 6 layers. Offline, the wider version gains 0.3% AUC and the deeper one nothing, both inside the seed spread at first; with five seeds the width gain holds and the depth gain does not, while the deeper model doubles serving latency. They ship the wider, shallower MLP. It is the same pattern as Fashion-MNIST: for an MLP on fixed features, width is cheap capacity and extra depth rarely pays.

⚠️
Common mistakes
  • Reading universal approximation as a guarantee: it promises the weights exist, not that training finds them. The 32-tooth sawtooth was not learned by any trained network.
  • Adding depth to an MLP by default: beyond two layers it added nothing on Fashion-MNIST.
  • Forgetting where the parameters are: the first layer held 75% of them; that is where to trim.
  • Judging capacity by training accuracy alone: 100% on spirals says nothing about new points (Chapter 27).
  • Putting an activation after the last layer of a classifier: emit logits.

Interview drill

Explain it simply: What does the universal approximation theorem say, and why isn’t it the end of the story?

How a strong answer sounds
It says a network with one hidden layer and a suitable non-linearity can approximate any continuous function on a bounded domain to any accuracy, given enough hidden units. With ReLU you can see why: each unit is a hinge and the output is a sum of hinges, a piecewise-linear function with as many pieces as you like. But it says nothing about how many units are needed, which can be exponential, or about whether gradient descent will find the right weights, or whether the result generalises. I measured a sawtooth that a five-layer network with 31 parameters represents exactly, yet no trained network, deep or shallow, learned it.

Deeper: Width or depth: how would you decide for an MLP on a tabular or embedding input?

How a strong answer sounds
In theory depth is more parameter-efficient for compositional functions: k layers of width 2 can represent a sawtooth with 2ᵏ teeth that one layer needs 2ᵏ units for. In practice, for an MLP on fixed features, extra depth is harder to optimise and often buys little, while width is cheap and reliable. I would start with two hidden layers, scale width first, and only add depth with normalisation and residual connections, comparing with several seeds. On Fashion-MNIST, width 32 to 512 gained about 2 points at every depth, while 1 to 4 layers gained at most 0.4, inside the seed spread.

🧠 Key takeaways

  • An MLP is linear layers with non-linearities between them; parameters scale with the product of neighbouring widths.
  • One hidden ReLU layer is a sum of hinges: more units, more linear pieces, a closer fit (MSE 0.42 → 0.0007).
  • Depth can be exponentially more efficient (a 32-tooth sawtooth in 31 parameters), but gradient descent may not find those solutions.
  • Capacity shows up as decision boundaries: spirals went from 63.5% (linear) to 99.3% with one layer of 64.
  • On Fashion-MNIST, width helped and depth beyond two layers did not; architecture matters more than depth for images.
