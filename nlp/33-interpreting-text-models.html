Interpreting Text Models

“Why did the model say that?” has many answers, and the popular ones disagree with each other. Attention weights, gradients and occlusion each produce a heat map over the input, and each heat map looks convincing. The useful question is which of them is faithful: whether the tokens it highlights are the ones the model actually relied on.

This chapter computes five explanations for a sentiment model, tests their faithfulness, and probes what BERT’s layers encode. Occlusion, the slowest and most literal method, was by far the most faithful: deleting the 20% of tokens it ranked highest lowered the model’s confidence by 0.553 on average, against 0.119 for a random 20%. Gradient × input was barely better than random on one of the two tests. The five methods agreed with each other only weakly (Spearman 0.1–0.45), and probes found part of speech in BERT’s embeddings before any layer had run.

Five ways to attribute a prediction

  • Attention: how much the [CLS] position attends to each token in the last layer, averaged over heads. Cheap and widely shown, and Jain and Wallace (2019) showed attention can often be changed a lot without changing the prediction.
  • Attention rollout (Abnar and Zuidema, 2020): multiply attention matrices through the layers, mixing in the residual connection, to trace how information flows from input to [CLS].
  • Gradient × input: the gradient of the predicted class’s logit with respect to each token’s embedding, times the embedding: a first-order estimate of each token’s contribution.
  • Integrated gradients (Sundararajan et al., 2017): average the gradient along a straight path from a baseline (here, all-[PAD] embeddings) to the real input, times the difference. It satisfies completeness: attributions sum to the logit difference between input and baseline.
  • Occlusion: replace each token with [MASK] and measure the drop in probability. Slow (one forward pass per token), and direct.

For a linear model these all coincide: a word’s contribution is its weight times its count. The lab’s first view shows that; the rest of the chapter is about how badly they diverge for a transformer.

Testing faithfulness

DeYoung et al. (2020) proposed two tests. Comprehensiveness: delete the top 20% of tokens by attribution; a faithful method’s top tokens should matter, so the probability should drop a lot. Sufficiency: keep only the top 20%; the prediction should survive, so the drop should be small. Any method should beat random attributions on both.

Every method beat random on both tests, but by very different margins. Occlusion’s top tokens, when deleted, lowered the predicted class’s probability by 0.553 on average, and kept on their own they preserved the prediction almost completely (a drop of 0.035). Integrated gradients came second (0.36 and 0.127). Part of occlusion’s advantage is that it measures almost exactly what these tests measure, the effect of removing a token, so it is the most “faithful” by construction; it also costs one forward pass per token. More surprising: last-layer attention from [CLS] (0.324, 0.165) did better than gradient × input (0.219, 0.298), whose sufficiency was close to random (0.374). Single-step gradients are local: they measure sensitivity to an infinitesimal change in the embedding, which says little about what happens when a token is removed entirely. These tests delete tokens and so produce unnatural inputs, which is why they count as evidence about faithfulness, not proof.

Do the methods agree?

Asked which tokens matter, the methods mostly disagreed. Spearman correlations between their token rankings, averaged over the 200 sentences, ranged from 0.1 to 0.45; the closest pair was the two attention methods (0.45), and occlusion agreed best with integrated gradients (0.34). In the lab’s first sentence, “it’s a charming and often affecting journey.”, occlusion put almost all the weight on “charming”; last-layer attention put its largest weight on “.”, a punctuation mark. Attention often parks on punctuation and separator tokens, a known pattern (Clark et al., 2019) that says more about how the model routes information than about why it predicted positive. If two explanation methods disagree, at most one of them can describe the model; the erasure tests above are how to decide which.

Probing: what do the layers encode?

A probe is a small classifier trained on a layer’s hidden states to predict a linguistic property, such as part of speech. High probe accuracy suggests the property is linearly readable from that layer. But a probe can also memorise: if it scores well on a control task that assigns each word a random fixed tag, it is learning word identity, not syntax. Selectivity, real accuracy minus control accuracy, is the honest number.

Linear probes on each layer of bert-base-uncased predicted the part-of-speech tag of each CoNLL-2003 word (23.91% for always guessing the commonest tag). Accuracy was already 84.2% on the embedding layer, before any attention, peaked at 90.0% at layer 4, and fell slightly to 86.91% at layer 12 as the top layers specialise for pre-training. The control task tells a different story. A probe asked to predict a random tag fixed for each word type scored 71.08% on the embeddings, because the embedding of a word identifies the word, and a word-to-tag lookup is easy to memorise. Selectivity, real minus control, was only 13.13 points at layer 0 and rose to about 41 by layer 11, mostly because control accuracy fell as context mixed word identity away. So the middle and upper layers encode part of speech in a way that is not just word lookup; the embedding layer’s high score is mostly memorisation. A probe shows what is linearly decodable, not what the model uses.

Use case: explaining loan-application text decisions to an auditor

A lender’s model reads applicants’ free-text explanations, and a regulator asks why a set of applications were scored as high-risk. The team’s first instinct is to show attention heat maps. Instead they compute integrated gradients and occlusion, check both against random with comprehensiveness and sufficiency on a few hundred cases, and report only where the two agree. The exercise also finds something worse than an explanation problem: the word “divorce” carries a large attribution, which leads to a fairness review (Ch31) rather than a slide.

⚠️
Common mistakes
  • Showing attention maps as explanations: last-layer attention put its top weight on a full stop in the first example, and agreed with occlusion at Spearman 0.18.
  • Trusting gradients as the cheap default: gradient × input’s sufficiency (0.298) was close to random (0.374).
  • Reporting probe accuracy without a control task: 84.2% part-of-speech accuracy on the embedding layer was mostly word lookup (control 71.08%).
  • Showing one example: a single heat map is an anecdote; report faithfulness over hundreds of sentences.
  • Forgetting the baseline in integrated gradients: attributions are relative to it; state which one you used.

Interview drill

Explain it simply: Is attention an explanation of a transformer’s prediction?

How a strong answer sounds
Not by itself. Attention weights say how much each position’s value vector was mixed into another position at one layer, in one head; the prediction depends on all heads, all layers, the residual stream and the feed-forward layers. Attention can be changed substantially without changing outputs (Jain and Wallace, 2019), and it often concentrates on punctuation and separators. In my measurements on DistilBERT, last-layer [CLS] attention did beat random on erasure tests, but occlusion was far more faithful (0.553 against 0.324 probability drop when the top tokens were removed), and the two agreed on token rankings only at Spearman 0.18. Attention is a useful view of information flow, not an explanation, unless it passes a faithfulness test.

Deeper: How would you evaluate whether an explanation method is faithful?

How a strong answer sounds
Erasure tests over hundreds of examples, against a random baseline: remove the top-k attributed tokens and measure the drop in the predicted class’s probability (comprehensiveness), and keep only those tokens and measure how much of the prediction survives (sufficiency). Here occlusion scored 0.553 and 0.035, random 0.119 and 0.374. Because deletion creates unnatural inputs, also check with methods that avoid it, such as retraining without the top tokens (ROAR) or replacing them with plausible alternatives. Sanity checks matter too: an explanation should change when the model’s weights are randomised and when the label changes (Adebayo et al., 2018). Compare methods with each other (agreement was weak here, 0.1–0.45) and, for the use case, test whether the explanation helps a person predict or debug the model.

🧠 Key takeaways

  • Measured: occlusion was the most faithful (comprehensiveness 0.553, sufficiency 0.035), then integrated gradients; gradient × input was close to random on sufficiency.
  • Measured: methods agreed weakly on which tokens mattered (Spearman 0.1–0.45); attention put weight on punctuation.
  • Measured: part-of-speech probes reached 84.2% on BERT’s embeddings, but a control task showed that was mostly word identity; selectivity peaked at layer 11.
  • Every explanation method should be tested against random with an erasure test.
  • A probe shows what is decodable, not what the model uses; use a control task.
