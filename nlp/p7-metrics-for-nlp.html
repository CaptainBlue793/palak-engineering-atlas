Metrics for NLP

A model is only as good as the number you judge it by, and NLP has an unusual talent for numbers that look excellent and mean little. Accuracy rewards ignoring rare classes. Token-level scores reward predicting “not an entity” everywhere. And a test set labelled by people inherits their disagreements, which sets a ceiling no model can pass.

This prerequisite measures each of those traps. On a four-class emotion dataset, a classifier’s 65% accuracy hides a 36% F1 on the rarest class. On the standard named-entity benchmark, a strong model scores 98.3% token accuracy and 91.3% span F1, while labelling nothing at all would score 82.5% token accuracy. And on 37,000 Reddit comments, each rated by three people, the raters agreed on “pride” barely better than chance.

  • Compute precision, recall and F1, and choose a decision threshold
  • Choose between micro, macro and weighted averages
  • Score entity spans rather than tokens
  • Read a confusion matrix and put a confidence interval on a score
  • Measure how much human annotators agree

Precision, recall and F1

For one class, call it positive, every prediction is a true positive (TP), false positive (FP), false negative (FN) or true negative. Precision = TP / (TP + FP): of what the model flagged, how much was right. Recall = TP / (TP + FN): of what was really there, how much the model found. F1 is their harmonic mean, 2PR / (P + R), which is high only when both are. Unlike accuracy, none of them counts true negatives, which is the point: in most NLP tasks the negatives (not offensive, not an entity, not relevant) vastly outnumber the positives.

from sklearn.metrics import precision_recall_fscore_support, average_precision_score
p = model.predict_proba(X_test)[:, 1]
P, R, F, _ = precision_recall_fscore_support(y_test, p >= 0.35, average="binary")   # the threshold is a choice
average_precision_score(y_test, p)       # area under the precision-recall curve: threshold-free

Precision and recall trade against each other through the threshold. On the tweet_eval offensive-language test set (860 tweets, 240 offensive), a TF-IDF logistic regression at the default threshold of 0.5 had precision 68.4% and recall 49.6%: it missed half the offensive tweets. Lowering the threshold to 0.35 gave the best F1, 59.1% (precision 56.4%, recall 62.1%). At 0.05 it found 96% of offensive tweets, but only 31% of what it flagged was offensive; at 0.9, 95% precision and 15% recall. Accuracy at 0.5 was 79.5%, against 72.1% for a model that flags nothing. Which point is right depends on the cost of each error, not on the model.

Micro, macro and weighted averages

With several classes, you get one precision, recall and F1 per class, and then a choice of how to combine them. Micro averaging pools every decision before computing, so frequent classes dominate; for single-label classification, micro F1 equals accuracy. Macro averaging computes F1 per class and takes the plain mean, so every class counts equally, however rare. Weighted averaging weights each class’s F1 by its frequency, which brings the frequent classes back. Measured on tweet_eval emotion, where anger is 39% of the test set and optimism 9%:

tweet_eval emotion, 1,421 test tweetsAccuracy (= micro F1)Macro F1Weighted F1Optimism F1
Always predict “anger”39.27%14.10%22.14%0.0%
TF-IDF + logistic regression65.38%58.27%64.20%35.6%
+ class weights (balanced)64.67%59.79%64.62%41.2%

The logistic regression’s accuracy is fair, and its weakness is invisible in it: on optimism, recall was 27.6%, and 56 of the 123 optimistic tweets were called angry. Class weights, which make each rare-class mistake cost more in training, raised optimism’s F1 from 35.6% to 41.2% and macro F1 by 1.5 points, at the cost of 0.7 points of accuracy. Report the average that matches what you care about, and the per-class scores whenever classes are imbalanced, because every average hides something.

Is the 1.5-point macro-F1 gain real? A bootstrap answers that: resample the 1,421 test tweets with replacement 1,000 times and recompute the score each time. The 95% interval for the logistic regression’s macro F1 was 55.0% to 61.4%, more than six points wide; for accuracy, 62.8% to 67.6%. A 1.5-point difference sits well inside that spread, so this test set alone cannot tell the two models apart with confidence. Comparing two models properly means resampling the same test examples for both and looking at the distribution of the difference, a paired bootstrap, and with a test set this small, expecting it to be wide.

Span-level scoring

Tasks that label parts of a text, such as named-entity recognition, are usually tagged token by token in the BIO scheme: B-PER starts a person name, I-PER continues it, O is outside any entity. But the unit that matters is the entity: “European Union” is one organisation, and getting “Union” alone is not half-right, it is wrong. CoNLL-2003 and nearly all NER work therefore score spans: a predicted entity is a true positive only if its start, end and type all match a gold entity exactly.

Token accuracy starts at 82.5% for doing nothing, so 98.3% is far less impressive than it sounds; span F1 is the honest number. By type, the model was best on people (95.7%) and worst on MISC (80.4%), the catch-all for nationalities, events and titles. Of its 535 wrong spans, 229 had the right boundaries but the wrong type, 156 overlapped a gold entity with the wrong boundaries, and 150 matched nothing; separately it missed 69 gold entities entirely. Some of those “errors” are the benchmark’s. The very first test sentence, “SOCCER - JAPAN GET LUCKY WIN, CHINA IN SURPRISE DEFEAT.”, labels CHINA as a person in the gold data. Studies of CoNLL-2003 have found label mistakes in around 5% of test sentences, which matters when papers compete over tenths of a point.

Inter-annotator agreement

Labels come from people, and people disagree. Before trusting a test set, or blaming a model, measure how often annotators agree. Raw agreement is misleading when one answer is common, because two raters who both say “no” to everything agree 95% of the time on a label that is 5% positive. Cohen’s kappa (two raters) and Fleiss’ kappa (several) subtract the agreement expected by chance: κ = (observed − chance) / (1 − chance). 1 is perfect; 0 is chance. A common rough scale calls 0.21–0.40 fair, 0.41–0.60 moderate and 0.61–0.80 substantial.

GoEmotions released every rater’s labels. On the 37,335 comments rated by exactly three people, agreement on gratitude was κ = 0.80, because “thank you” is unambiguous; love 0.61 and amusement 0.55. At the bottom, pride (0.21), grief (0.22), nervousness (0.23) and realization (0.23) were barely fair. When one rater marked grief, all three did only 2% of the time. A model trained and tested on such labels cannot meaningfully exceed the raters’ own consistency; a low score on those classes may be the label’s fault, not the model’s.

Use case: setting the threshold for an abuse filter

A forum’s abuse classifier is reported at “80% accuracy”. The moderators ask what that means for them. The team re-reports it as a precision-recall curve on a month of labelled posts and asks two questions: how many posts can moderators review per day, and how bad is a missed post? Review capacity sets a floor on precision, the harm of a miss sets a floor on recall, and the threshold is chosen between them: about 0.35 on curves like the one above, not the default 0.5. They report recall per abuse type, because a macro view shows threats are caught far less often than insults, and they measure kappa between two moderators on 300 posts. It is 0.45, so they also write clearer labelling guidelines before training the next model.

⚠️
Common mistakes
  • Reporting accuracy on imbalanced data: “always anger” scored 39% accuracy and 14% macro F1; a no-op offensive filter scored 72% accuracy.
  • Keeping the default 0.5 threshold: it found half the offensive tweets; 0.35 gave the best F1.
  • Scoring NER by tokens: predicting nothing scores 82.5% token accuracy.
  • Hiding per-class scores behind an average: 65% accuracy concealed 36% F1 on optimism.
  • Comparing models without an interval: a 1.5-point difference sat inside a 6-point bootstrap interval.
  • Treating gold labels as truth: raters agreed at κ ≈ 0.2 on some emotions, and CoNLL’s first test sentence calls China a person.

Interview drill

Explain it simply: What are precision and recall, and how do you decide which matters more?

How a strong answer sounds
Precision is how many of the things the model flagged were right; recall is how many of the real ones it found. You trade one for the other by moving the decision threshold: on an offensive-tweet classifier, a threshold of 0.5 gave 68% precision and 50% recall, 0.05 gave 31% and 96%. Which matters more is a business question: if every flag costs a human review, precision; if a miss causes harm, recall. I would show the whole precision-recall curve, agree the costs with the people affected, and pick the threshold from that, rather than report F1 at 0.5 by default.

Deeper: Your NER model has 98% token accuracy. Is it good, and how would you evaluate it properly?

How a strong answer sounds
Not necessarily. Most tokens are outside any entity, so predicting O everywhere already scores about 82% on CoNLL-2003. I would report strict span-level precision, recall and F1, where an entity counts only if its start, end and type all match: the same kind of model scored 98.3% token accuracy but 91.3% span F1. Then break it down by entity type, since MISC was 15 points worse than PER, and by error type: wrong type, wrong boundary, spurious, missed. I would look at examples, because some disagreements are gold-label errors, and put a bootstrap interval on the F1 before comparing it with anything.

🧠 Key takeaways

  • Precision, recall and F1 ignore true negatives; the threshold trades precision for recall, so choose it from the costs.
  • Micro F1 is accuracy for single-label tasks; macro F1 weights every class equally and exposes rare-class failures.
  • Score entities as exact spans: token accuracy was 98.3%, span F1 91.3%, and doing nothing scores 82.5% token accuracy.
  • Put a bootstrap interval on every score: here macro F1 was 58.3% with a 95% interval six points wide.
  • Measure annotator agreement: kappa ranged from 0.80 (gratitude) to 0.21 (pride) on the same dataset.

Check your understanding

A model flags 100 tweets as offensive; 60 really are. There were 150 offensive tweets in total. What are its precision and recall?

Precision = 60 / 100; recall = 60 / 150.

For single-label multi-class classification, micro-averaged F1 equals what?

Pooling every decision, each error is one false positive for one class and one false negative for another, so micro P = micro R = accuracy.

An NER model predicts “Union” as ORG where the gold entity is “European Union” (ORG). How does strict span scoring count it?

The boundaries do not match, so the predicted span is wrong and the gold span is missed.

Two raters label a rare emotion. They agree 96% of the time, mostly by both saying “no”. Why is kappa better than raw agreement here?

Two raters who say “no” to everything agree almost always; kappa would be 0.

Model B beats model A by 1.5 points of macro F1 on a 1,421-example test set. The bootstrap 95% interval of A’s macro F1 is six points wide. What can you conclude?

Small differences on small test sets are often noise; a paired comparison is more sensitive than two separate intervals.
