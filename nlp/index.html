One code style, all the way through

Every listing is Python with PyTorch, scikit-learn and Hugging Face, run on one 16 GB GPU, and follows the same five rules, so each one is also a small lesson in text code whose numbers you can trust. This is the style, stated once and never broken.

  • Tokens shown, not assumed. Listings print what the tokeniser produced, because casing, accents, subwords and truncation decide what the model actually reads.
  • Lengths and truncation stated. Maximum length, padding side and truncation side are written down, because text longer than the limit is cut without an error.
  • Pinned and seeded. Model names, library versions and random seeds are fixed, so every number on the page can be reproduced.
  • Baselines first. Every neural model is compared with TF-IDF and a linear classifier on the same split, because the cheap baseline often wins.
  • Errors read by hand. Metrics come with a sample of the mistakes, because a 92% model can be systematically wrong about one thing.
import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification

NAME = "distilbert-base-uncased-finetuned-sst-2-english"  # pinned model, transformers 5.20
tok = AutoTokenizer.from_pretrained(NAME)
model = AutoModelForSequenceClassification.from_pretrained(NAME).to("cuda").eval()

text = "The plot was predictable, but the acting was not bad at all."
print(tok.tokenize(text))                                # 14 lower-cased word pieces
enc = tok(text, truncation=True, max_length=512, return_tensors="pt").to("cuda")
with torch.no_grad():
    p = model(**enc).logits.softmax(-1)[0]                # (2,) NEGATIVE, POSITIVE
print(enc["input_ids"].shape, p.tolist())                  # (1, 16) with [CLS] and [SEP]

On this GPU the short review came out 99.4% positive: “not bad at all” read correctly, although the sentence also says “predictable”. Now write a 662-token review: forty sentences of praise and a final verdict, “it was awful and I want my money back.” With truncation=True the tokeniser keeps the first 512 tokens, the verdict is never seen, and the model says 99.99% positive without a warning in the result. The verdict alone scores 99.9% negative. Keeping the last 512 tokens instead still gave 99.98% positive, because the praise outweighs one sentence. Long documents need a strategy, not a flag (Chapter 34), and that silent cut is why lengths are always written down (Chapter 39).
