One code style, all the way through

Every listing is Python with asyncio and a local model served by Ollama, and follows the same five rules, so each one is also a small lesson in building a team of agents you can trust. This is the style, stated once and never broken.

  • Beat one agent first. Every multi-agent design is compared with a single agent on the same tasks, for accuracy, time and tokens.
  • Briefs carry the context. A worker sees only what it is given, so every task brief states the goal, the inputs, the method and the expected output.
  • Agents exchange typed messages. Findings pass between agents as structured data checked against a schema, not as free text.
  • Every agent has limits. Steps, time, tokens and concurrency are bounded per agent and for the whole run, and failures come back as data.
  • Each agent gets only its own privileges. A worker that reads cannot write, and text from another agent is data, not instructions.
import asyncio, json
from ollama import AsyncClient

FINDING = {"type": "object", "properties": {"service": {"type": "string"},
           "status": {"enum": ["own errors", "errors from another service", "healthy"]},
           "caused_by": {"type": ["string", "null"]}, "newest_deploy": {"type": ["string", "null"]}}}

async def worker(service: str) -> dict:
    """One agent, one service, its own context; it reports a typed finding."""
    messages = [{"role": "system", "content": WORKER_BRIEF}, {"role": "user", "content": f"Check {service}."}]
    await agent_loop(messages, TOOLS, max_steps=6)              # the Single Agent loop, async
    messages.append({"role": "user", "content": "Report your finding."})
    reply = await client.chat(model="qwen3:14b", messages=messages, format=FINDING)
    return json.loads(reply.message.content)

async def orchestrate(services: list[str]) -> str:
    findings = await asyncio.gather(*(asyncio.wait_for(worker(s), timeout=120) for s in services),
                                    return_exceptions=True)          # one failed worker is data, not a crash
    notes = [f if isinstance(f, dict) else {"service": s, "status": "failed"} for s, f in zip(services, findings)]
    return await lead(json.dumps(notes))                      # the lead sees findings, not transcripts

An orchestrator sends one worker per service at the same time and gives the lead only their typed findings. On one of the course's simulated incidents it took two fixes to get right. With free-text notes, every worker copied the brief's template ("own errors | errors from … | healthy") and the lead blamed the wrong service. With typed findings but no method in the brief, the payments worker called its own certificate errors "from another service". With the schema and the method, four workers in 10 seconds gave the lead what it needed to name payments v4.18.1, the right answer, although two of them still marked healthy services as having errors of their own.
