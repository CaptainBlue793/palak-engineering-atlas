One code style, all the way through

Every listing is Python with NumPy, pandas and scikit-learn, and follows the same five rules, so each one is also a small lesson in not fooling yourself. This is the style, stated once and never broken.

  • Split first. The test set is carved off before anything is fitted, and touched once, at the end.
  • Preprocessing lives in a pipeline. Scalers, encoders and imputers are fitted on training rows only, inside Pipeline, so cross-validation cannot leak.
  • A baseline before a model. Every result is printed next to a DummyClassifier or DummyRegressor, so "0.92" always has something to beat.
  • A score comes with its spread. Cross-validated mean ± standard deviation, never a single lucky number.
  • Seeded and vectorised. Every split and model takes a random_state, and NumPy does the arithmetic, never a Python loop over rows.
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.dummy import DummyClassifier

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)  # split first

model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
base = DummyClassifier(strategy="most_frequent")

for name, est in [("baseline", base), ("logreg", model)]:
    s = cross_val_score(est, X_train, y_train, cv=5, scoring="roc_auc")
    print(f"{name:9s} AUC {s.mean():.3f} ± {s.std():.3f}")

The scaler sits inside the pipeline, so each of the five folds re-fits it on its own training rows. Fitting it on all of X before splitting is the most common leak there is (Chapter 37), and the baseline's AUC of 0.5 is the number the model has to beat.
