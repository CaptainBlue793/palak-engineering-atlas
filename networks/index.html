One code style, all the way through

Every listing in this course is Python 3 sockets or a real command with its real output, written the same way, so the shape of the code becomes a memory aid instead of noise. This is the style, stated once and never broken.

  • Bytes on the wire, strings in the program. Encode to UTF-8 when sending and decode when receiving, explicitly, at the edge. Never let str and bytes mix.
  • Every socket has a timeout. A peer that goes silent must not hang your program forever: settimeout() or create_connection(..., timeout=), every time.
  • TCP is a byte stream, so frame your messages. recv() may return part of a message, or two at once; loop until you have a whole one, using a length prefix or a delimiter.
  • Close what you open. Sockets live in with blocks, so they are closed on every path, including errors.
  • Show the command and its real output. Every curl, dig, ss and tcpdump listing shows what you type and what comes back, trimmed, with the important fields explained.
import socket, struct

def recv_exact(sock: socket.socket, n: int) -> bytes:
    """Read exactly n bytes. recv() may return fewer."""
    buf = bytearray()
    while len(buf) < n:
        chunk = sock.recv(n - len(buf))
        if not chunk:                          # the peer closed the connection
            raise ConnectionError(f"closed after {len(buf)} of {n} bytes")
        buf += chunk
    return bytes(buf)

def recv_message(sock: socket.socket) -> bytes:
    (length,) = struct.unpack("!I", recv_exact(sock, 4))   # 4-byte big-endian length
    return recv_exact(sock, length)

A dozen lines that turn TCP's byte stream back into messages. HTTP/2 frames, TLS records and gRPC messages all solve the same problem the same way: a length prefix.
