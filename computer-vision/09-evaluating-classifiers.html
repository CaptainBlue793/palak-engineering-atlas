Evaluating Image Classifiers

A test accuracy of 92.9% answers one narrow question: how often the model is right on images drawn exactly like its training set, scored once. Deployment asks different ones. Which classes fail? When the model says 99%, is it right 99% of the time? What happens on new photos taken a little differently, or slightly blurred? And is the 92.9% itself honest, or was it chosen by peeking?

This chapter asks each of those of a ResNet-18 trained on CIFAR-10 here. Its accuracy fell 7.7 points on a fresh test set collected years later the same way as the original; a little Gaussian noise took it below 20%; its most confident mistakes were 100% certain; and one parameter, fitted in a second, fixed its calibration.

  • Break accuracy down by class and find where the errors concentrate
  • Measure calibration with a reliability diagram and ECE, and fix it with temperature scaling
  • Explain why a fresh test set scores lower, and what distribution shift is
  • Test robustness to corruptions before deployment
  • Avoid test-set reuse, and use error analysis to decide what to fix

The model and the splits

ResNet-18 (Chapter 7’s CIFAR version, 11.2 M parameters), trained for 30 epochs on 45,000 training images, with the other 5,000 held out as a validation set: used for every decision (here, fitting the calibration temperature), never for training. The 10,000 test images were looked at once, at the end. A second copy was trained with label smoothing 0.1. Test accuracy: 92.88% (92.68% with label smoothing); validation 93.20%.

Per-class accuracy

92.9% overall hides a spread from 84.5% (cat) to 97.8% (automobile). As in P7, cat and dog are the weakest pair (89.4% for dog), and their errors mostly go to each other. For a product, the question is whether the weak classes are the ones that matter. If they are, the next step is more data for those classes, or a threshold per class, not a different architecture.

Calibration: does 90% mean 90%?

A model is calibrated if, among all the images it labels with 90% confidence, 90% are right. The reliability diagram sorts predictions into confidence bins and plots each bin’s accuracy against its confidence; a calibrated model sits on the diagonal. The expected calibration error (ECE) is the average gap, weighted by how many predictions fall in each bin.

The ResNet-18’s mean confidence was 96.3% while its accuracy was 92.9%: overconfident, with an ECE of 3.55%. Training drives cross-entropy towards zero on the training set by making the logits large, so test predictions inherit that overconfidence. Temperature scaling divides every logit by one number T before the softmax, fitted to minimise the loss on the validation set. It cannot change any prediction (dividing by a positive number keeps the order), only the confidence:

def fit_temperature(val_logits, val_labels):               # (5000, 10) logits, (5000,) labels
    log_t = torch.zeros(1, device="cuda", requires_grad=True)
    opt = torch.optim.LBFGS([log_t], lr=0.1, max_iter=200)
    def closure():
        opt.zero_grad(); loss = F.cross_entropy(val_logits / log_t.exp(), val_labels); loss.backward(); return loss
    opt.step(closure)
    return log_t.exp().item()                                 # T = 1.574 for this model
probs = (test_logits / T).softmax(-1)                            # same argmax, calibrated confidence

T = 1.574 brought the ECE from 3.55% to 0.72% and the test negative log-likelihood from 0.253 to 0.216, at no cost in accuracy. The label-smoothed model was the opposite: underconfident (T = 0.762, ECE 6.24%), because label smoothing trains towards targets of 0.91 rather than 1.0. Temperature scaling fixed it to 1.74%. Calibration matters whenever a threshold is applied to the probability, the probability is shown to a person, or the outputs of several models are combined.

A fresh test set

In 2018 Recht and colleagues collected CIFAR-10.1: 2,000 new images gathered from the same source (the Tiny Images collection) with the same labelling rules as the original, to test whether models had really learned CIFAR-10 or the particular 10,000 test images everyone had been tuning against for a decade. This chapter’s ResNet-18 scored 92.88% on the original test set and 85.20% on CIFAR-10.1, a drop of 7.7 points, close to the drops the paper reported for published models. Every class fell, airplane and automobile by 11–17 points, frog and truck by about 4–5.

Their conclusion, which this result agrees with, was mostly not overfitting to the test set by researchers: the gap persists for models whose test score was never tuned. It is a small distribution shift: the new images are drawn by the same procedure but differ subtly in which photos were picked. A model is only as good as the match between its test data and the data it will meet, and real deployments shift far more than this: new cameras, seasons, regions, user populations.

Corruptions

Common image corruptions, applied at three severities to the whole test set (in the style of the CIFAR-10-C benchmark, generated here):

Noise of σ = 16 grey levels, visible but hardly destructive to a person, cut accuracy from 92.9% to 54.4%; a 2-pixel blur to 77.0%. The model is robust to changes resembling its augmentations (brightness, contrast) and fragile to ones it never saw (noise, blur, compression). That pattern is general, and it is why robustness is tested per corruption type rather than with one number. Chapter 37 measures adversarial robustness and what training against it costs.

Test-set reuse and error analysis

Every time a configuration is chosen because it scored best on some data, that score becomes optimistic for the chosen configuration. To measure it, 12 small CNNs (four learning rates, two weight decays, two widths) were trained, and the test set was split into two random halves A and B. Choosing the best by half A picked a model scoring 86.28% on A and 85.38% on B. Part of that 0.9-point drop is just that half A was slightly easier for every model (by 0.61 points on average); the remaining 0.3 points is selection: the winner on A was partly lucky on A. With 12 candidates the effect is small. With hundreds of tuning runs against one test set, it is not, which is why decisions are made on validation data and the test set is scored once.

The most useful single evaluation, though, is reading errors. The 12 test images the ResNet-18 got wrong with the highest confidence (all at 99.9–100%) include several where the image is genuinely ambiguous or the label is arguable at 32 × 32: confident errors are where label noise and dataset quirks hide (Chapter 39 finds mislabelled training images the same way, by their loss).

🧾
Use case: ImageNetV2

The same authors repeated the experiment for ImageNet: ImageNetV2, a new 10,000-image test set collected with ImageNet’s original procedure. Across dozens of published models, accuracy fell by about 11 to 14 points, yet the ranking of models was almost perfectly preserved: models better on the old test set were better on the new one by about the same margin. Two lessons for practice. Absolute accuracy on a benchmark says little about accuracy on new data from the “same” distribution; but comparisons between models made on a fixed, honestly used test set do transfer. Measure on your own fresh data before quoting a number to anyone who will rely on it.

⚠️
Common mistakes
  • Reporting one accuracy without per-class numbers, so the weak classes stay invisible.
  • Reading softmax outputs as calibrated probabilities. This model was 3.4 points overconfident on average.
  • Fitting temperature, thresholds or early stopping on the test set. Use validation data.
  • Expecting test accuracy to hold on new data. A fresh test set from the same recipe cost 7.7 points.
  • Testing only clean images when deployment brings noise, blur and compression.
  • Never looking at the errors, where label noise and shortcuts are found.

Interview drill

Explain it simply: What is temperature scaling, and why does it not change accuracy?

How a strong answer sounds
It divides all the logits by a single learned number T before the softmax. T is fitted on a held-out validation set by minimising cross-entropy, so it is a one-parameter fit that takes seconds. Dividing by a positive constant keeps the order of the logits, so the predicted class never changes and accuracy is identical; only the confidence changes, softer for T > 1 and sharper for T < 1. Here a ResNet-18 was overconfident (mean confidence 96.3% at 92.9% accuracy); T = 1.57 cut its expected calibration error from 3.55% to 0.72%. A model trained with label smoothing was underconfident and needed T = 0.76.

Deeper: Your model scores 93% on the test set and 85% on a newly collected test set from the same pipeline. What happened, and what do you report?

How a strong answer sounds
That is what happened to this chapter’s ResNet-18 with CIFAR-10.1 (92.9% → 85.2%) and to published models on ImageNetV2. Possible causes: overfitting to the old test set through repeated tuning (check: does the gap also appear for models never tuned against it?), a subtle distribution shift in how the new images were sampled or labelled (check: per-class drops, a classifier trained to tell old from new images), or label differences. The research result is that most of the gap is shift, and that model rankings survive it. I would report the fresh-set number as the honest estimate, add per-class and per-slice results, stop tuning against either test set, and set up a regularly refreshed evaluation set drawn from real deployment traffic.

🧠 Key takeaways

  • Per-class accuracy ranged from 84.5% (cat) to 97.8% (automobile) behind a 92.9% average.
  • The ResNet-18 was overconfident (ECE 3.55%); temperature scaling with T = 1.57 brought it to 0.72% without changing a prediction.
  • Label smoothing made it underconfident (T = 0.76): calibrate after training either way.
  • A fresh test set drawn the same way (CIFAR-10.1) cost 7.7 points: expect shift, and measure on new data.
  • Noise of σ = 16 cut accuracy to 54%; robustness follows the augmentations seen in training.
  • Decide on validation data, score the test set once, and read the most confident errors.

Training data is overfit (too confident); fitting on the test set makes the test score optimistic. Here 5,000 held-out training images were used.
