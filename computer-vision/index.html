One code style, all the way through

Every listing is Python with PyTorch and torchvision, run on one 16 GB GPU, and follows the same five rules, so each one is also a small lesson in vision code whose numbers you can trust. This is the style, stated once and never broken.

  • Shapes in the comments. Every tensor line says its shape, (N, C, H, W), because most bugs in vision code are shape bugs.
  • Preprocessing stated exactly. Channel order, resize, crop, value range, mean and std are written down, because a model fed BGR or 0–255 pixels still runs and is quietly wrong.
  • Pinned and seeded. Weight versions, library versions and random seeds are fixed, so every number on the page can be reproduced.
  • Measured on this GPU. Times are taken after torch.cuda.synchronize() and memory from torch.cuda.max_memory_allocated(), never guessed.
  • Small before big. A new model overfits one batch and matches a reference implementation before any long run.
import torch
from torchvision.models import resnet50, ResNet50_Weights
from skimage import data

W = ResNet50_Weights.IMAGENET1K_V2                      # pinned weights, torchvision 0.26
model = resnet50(weights=W).to("cuda").eval()
pre = W.transforms()                                    # resize 232, crop 224, /255, ImageNet mean/std

img = torch.from_numpy(data.chelsea()).permute(2, 0, 1)  # (3, 300, 451) uint8, RGB
x = pre(img).unsqueeze(0).to("cuda")                   # (1, 3, 224, 224) float32
with torch.no_grad():
    p = model(x).softmax(-1)[0]                         # (1000,) class probabilities
top = p.topk(3)
print([(W.meta["categories"][i], round(v.item(), 3)) for v, i in zip(*top)])

A ResNet-50 looks at scikit-image’s photo of Chelsea the cat. On this GPU the top three were “Egyptian cat” at 33.9%, “tabby” at 6.0% and “tiger cat” at 4.9%: the right kind of answer, with less confidence than you might expect, because these weights were trained with label smoothing (Chapter 9). Feed the same photo with its channels flipped to BGR and the order changes to tiger cat 16.6%, tabby 14.6%, Egyptian cat 10.0%, with no error raised. That silent failure is why preprocessing is always written down (Chapter 39).
