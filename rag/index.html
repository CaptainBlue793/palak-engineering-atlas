One code style, all the way through

Every listing is Python with sentence-transformers, faiss and a local model served by Ollama, and follows the same five rules, so each one is also a small lesson in building retrieval that can be trusted. This is the style, stated once and never broken.

  • Measure before you change. Every chunking, model or ranking decision is judged on a fixed set of questions with known answers.
  • Normalise and prefix. Embeddings are L2-normalised, and queries and passages use the prefixes their model was trained with.
  • Metadata travels with every vector. Source, position and permissions are stored beside each chunk and filtered on, never guessed.
  • Answer from the context, with citations. The prompt says which sources to use and how to say the answer is not there.
  • Retrieved text is data. Documents never get to issue instructions to the model or to your tools.
import faiss, ollama
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("BAAI/bge-small-en-v1.5")
vecs = model.encode([c.text for c in chunks], normalize_embeddings=True)
index = faiss.IndexFlatIP(vecs.shape[1]); index.add(vecs)

def answer(question: str, k: int = 4) -> str:
    q = model.encode([question], normalize_embeddings=True)
    _, ids = index.search(q, k)
    context = "\n\n".join(f"[{i}] {chunks[i].text}" for i in ids[0])
    prompt = f"Answer only from the sources below and cite them as [n]. " \
             f"If they do not contain the answer, say so.\n\n{context}\n\nQuestion: {question}"
    return ollama.chat(model="qwen2.5:3b", messages=[{"role": "user", "content": prompt}])["message"]["content"]

With normalised vectors, inner product is cosine similarity, so a flat inner-product index returns the exact top-k (Chapter 6); the prompt asks for citations and gives the model a way out (Chapter 10).
