The Transformer Block

Attention moves information between positions. A transformer block wraps it with three more pieces: an MLP that transforms each position on its own, residual connections that add each piece's output to a running total instead of replacing it, and normalisation that keeps the numbers in range. Stack a dozen of these and you have GPT-2; stack eighty and you have a frontier model.

This chapter writes the block in ten lines, matches it to GPT-2's to within 0.000004, and then reads GPT-2's running total layer by layer: " Paris" only becomes its best guess after 11 of its 12 blocks. Then it trains small 12-layer models on WikiText-2. Without residual connections the model learnt nothing beyond word frequencies. And post-norm, the original 2017 design, trained fine at a low learning rate but stalled completely at higher ones, where pre-norm kept learning.

The residual stream

A transformer block does not replace its input. It computes something and adds it: x = x + attention(norm(x)), then x = x + mlp(norm(x)). The vector that flows from the embedding to the output, collecting every block's additions along the way, is called the residual stream. Each block reads the stream, and writes a correction into it.

def block_forward(b, x):                                   # b: one of GPT-2's blocks, x: (1, T, 768)
    h = b.ln_1(x)
    q, k, v = b.attn.c_attn(h).split(768, dim=2)
    sh = lambda t: t.view(1, T, 12, 64).transpose(1, 2)
    a = F.scaled_dot_product_attention(sh(q), sh(k), sh(v), is_causal=True)
    x = x + b.attn.c_proj(a.transpose(1, 2).reshape(1, T, 768))          # residual 1: add what attention found
    m = b.mlp.c_proj(F.gelu(b.mlp.c_fc(b.ln_2(x)), approximate="tanh"))   # MLP: 768 → 3,072 → 768
    return x + m                                                  # residual 2: add what the MLP computed

Given the real input of GPT-2's seventh block, this reproduced the block's output to within 3.8 × 10⁻⁶. The additions matter for training. The gradient of x + f(x) with respect to x always includes an identity term, so a signal from the loss reaches the first block directly, however many blocks are stacked; each block only has to learn a small change. In GPT-2 on WikiText the stream grows as blocks add to it: an average length of 4.6 after the embeddings, 51 after one block, 87 after seven and 220 after eleven.

Because every block writes into the same space, you can stop part-way and ask what the stream would predict if the model ended there: apply the final norm and the output matrix to the stream after n blocks. This trick is called the logit lens. For "The Eiffel Tower is located in the city of":

Blocks appliedBest guessNext
1–5" the"(a generic continuation)
6–9" England", " East", " Ing", " Rome"places, but the wrong ones

The answer forms late: early blocks settle what kind of word comes next, later ones which word. The last block also made the model less confident; on a Python prompt the stream was 97% sure of " +" after 11 blocks and 30% after all 12. The logit lens is an approximation, since the output matrix was trained only for the final layer, but it is a cheap way to see a model's computation unfold.

The MLP and its width

After attention, each position goes through a small two-layer network on its own: widen from 768 to 3,072 dimensions, apply GELU, narrow back to 768. Attention mixes between positions; the MLP is where most of the per-token computation, and much of what a model knows, lives. It also holds most of the parameters:

The 4× widening is a convention from the 2017 paper, not a law; Qwen2.5-0.5B widens 896 to 4,864 (5.4×), with a gated variant of the MLP that Chapter 15 covers. Removing whole pieces of GPT-2, one at a time, on 5,120 tokens of WikiText (baseline loss 3.878), shows how unequal the layers are:

  • Removing layer 0's MLP (the first block's; layers are counted from 0 as in Chapter 5) added 4.69 to the loss, more than anything else; the model leans on it to turn raw token embeddings into something the rest can use.
  • Removing layer 0's attention added 2.55. (Chapter 5 removed the same heads but kept the layer's output bias, and the loss rose only 0.66: even a bias vector was something the rest of the model depended on.)
  • Removing any other single attention or MLP layer added between 0.02 and 0.30.

Pre-norm vs post-norm

The 2017 Transformer normalised after each addition: x = norm(x + attention(x)), called post-norm. GPT-2 and every major model since normalise the branch input instead and leave the stream alone, pre-norm. The difference sounds cosmetic. To test it, the same 12-layer model (d = 256, 4 heads, 22.4 million parameters, 12.9 million of them the tied 50,257-token vocabulary) was trained three ways for 800 steps on WikiText-2, at three learning rates, with no warm-up and no gradient clipping, so nothing hides an instability:

Pre-norm, no residual connections7.567.577.54
Predicting word frequencies only7.48

Three findings. Without residual connections, a 12-layer model learnt nothing beyond how common each token is: its loss sat at the level of a frequency table, 7.48, at every learning rate. Post-norm, at the lowest rate, was actually slightly better than pre-norm, 5.95 against 6.04; it is not broken. But at the two higher rates it stalled at the same frequency-table level, while pre-norm kept learning. Post-norm puts a normalisation on the main path after every block, so the gradient reaching early layers is reshaped twelve times over; it needs a careful warm-up and a small learning rate to train. Pre-norm leaves a clean path through the additions, which is why it tolerates aggressive settings, and why everyone uses it.

Dropout and when to drop it

Dropout zeroes a random fraction of activations during training so the model cannot rely on any one of them. GPT-2 used 0.1; most large language models pretrained since use 0, because they see each token about once and overfitting is not the problem. With few epochs it costs learning speed for nothing; it can earn its keep when the same data is seen many times. A 6-layer version of the model above, trained on the same 2.4 million tokens for 3,000 steps (about 5 passes):

Dropout narrowed the gap between training and validation loss as the passes went on, a sign it was resisting memorisation, but it did not improve validation loss: dropout led by 0.04 early on, trailed by up to 0.03 in the middle, and finished 0.01 behind. At five passes over this little data it had not yet paid for itself. Fine-tuning on a small dataset for many epochs is where it is more often worth testing (Chapter 19).

Stacking blocks

A model is the embedding, N identical blocks with their own weights, a final norm and the output matrix. GPT-2 small has 12 blocks of width 768; Qwen2.5-0.5B 24 of 896; Qwen2.5-7B 28 of 3,584. Depth gives more steps of computation, each refining the stream; width gives each step more room. The logit lens above shows what depth buys: twelve blocks to get from " the" to " Paris". Use case: reading a model's intermediate guesses

The logit lens was introduced on a blog in 2020 (by the pseudonymous author "nostalgebraist") for GPT-2, and grew into a family of interpretability tools. The tuned lens (2023) trains a small linear translator per layer instead of reusing the final output matrix, which makes early layers' guesses far more accurate. Teams use these to debug fine-tunes, to see at which depth a fact becomes available, and to pick which layer to read features from or to attach a probe or early-exit head. Early exit is the production version: if the stream is already confident by block 20 of 32, stop and save the rest, which is one route to faster inference, alongside speculative decoding (Chapter 27).

⚠️
Common mistakes
  • Writing x = attention(x) instead of x = x + attention(...); without residuals a 12-layer model learnt only word frequencies.
  • Normalising the stream after each addition (post-norm) with an aggressive learning rate; it stalled at 1e-3 where pre-norm trained.
  • Forgetting the final norm before the output matrix in a pre-norm model; the stream's length grew to 220 by the last block.
  • Assuming the MLP is a detail; it is two thirds of each block, and removing GPT-2's first one hurt more than anything else.
  • Using dropout by habit in pretraining; over 5 passes it finished 0.01 behind no dropout.
  • Treating the logit lens as exact for early layers; the output matrix was trained only on the last.

Interview drill

Explain it simply: What is inside a transformer block?

How a strong answer sounds
Two sub-layers, each wrapped in a residual connection. First, layer norm then multi-head self-attention, whose output is added back to the input; this moves information between positions. Second, layer norm then an MLP, typically widening four times with a GELU or a gated activation and narrowing back, also added back; this processes each position on its own and holds about two thirds of the block's parameters. The running vector that blocks add into is the residual stream, so each block learns a correction rather than a replacement, and gradients have a direct path back to early layers. I wrote one in about ten lines and it matched GPT-2's block to 4e-6. A model is the embedding, a stack of these blocks, a final norm and the output matrix.

Deeper: Why did the field move from post-norm to pre-norm?

How a strong answer sounds
Post-norm normalises the stream after every residual addition, so the main path from the loss to the first layer passes through a norm at every block, which distorts gradient sizes across depth and makes training sensitive to the learning rate and dependent on warm-up. Pre-norm normalises only the input to each branch, leaving an identity path through all the additions. I tested it with a 12-layer model on WikiText-2, no warm-up and no clipping: at a learning rate of 3e-4 post-norm was fine, even slightly better, but at 1e-3 and 3e-3 it stalled at the loss of a word-frequency model while pre-norm kept learning. The trade-off is that pre-norm's stream keeps growing with depth, so a final norm is needed before the output, and some later work revisits post-norm-like variants for very deep models to get its slightly better results stably.

🧠 Key takeaways

  • A block is x + attention(norm(x)) then x + MLP(norm(x)); written from scratch it matched GPT-2 to 3.8 × 10⁻⁶.
  • The residual stream collects every block's additions; the logit lens showed " Paris" emerging only after 11 of 12 blocks.
  • The MLP holds two thirds of each block's parameters; GPT-2's first MLP mattered most of all.
  • Without residuals, a 12-layer model learnt only word frequencies.
  • Post-norm trained at a low learning rate but stalled at higher ones; pre-norm trained at all three.
  • Dropout narrowed the train–validation gap but did not improve validation loss over five passes.
